# BMI INDEX

A simple BMI (Body Mass Index) Calculator to help users determine their BMI based on their weight and height. This application calculates the BMI and provides feedback on the user's health category (Underweight, Normal weight, Overweight, or Obese).

## Features

- User-friendly interface
- Real-time BMI calculation
- Displays BMI category (Underweight, Normal weight, Overweight, Obese)
- Mobile responsive design
- Lightweight and fast

Usage
1. Enter your weight in kilograms (kg).

2. Enter your height in meters (m).

3. Click the Calculate button.

4. View your BMI and the corresponding health category.

BMI Categories
1. Underweight: BMI < 18.5

2. Normal weight: 18.5 ≤ BMI < 24.9

3. Overweight: 25 ≤ BMI < 29.9

4. Obese: BMI ≥ 30
